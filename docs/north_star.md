# NON WORKS North Star

最終更新: 2026-08-08 20:06 JST

## 目的

`nonworks.online` を、NON WORKSが公開するプロダクトとデザイン品質を一か所で確認できる公式の入口として育てる。

## 判断基準

- 公開中の実装・URL・説明を一致させる
- 作品ページから公式トップへ戻れる関係を保つ
- 架空作品は実在サービスと誤認されない表記を残す
- スマホ、キーボード操作、動きの軽減設定を含めて品質を確認する
- `main` は本番、機能追加は `codex/` ブランチで検証してから統合する
- 作品ごとのソースと静的出力の対応を、コミット・PR・引き継ぎ文書で追跡できる状態にする

## 次の北極星

1. 実スピーカーで受け入れ済みのLUMEN PR #3を `main` へ統合し、本番導線と音響を再検証する
2. LUMENとNORDLYSからNON WORKS公式トップへ戻る導線を追加するか判断する
3. NORDLYSとLUMENのNext.jsソースをGitHub上の永続的な正本へ移し、静的出力との対応を明確にする
4. Lighthouse、キーボード操作、スマホ実機を含む公開後の品質監査を行う
