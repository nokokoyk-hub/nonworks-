# NON WORKS North Star

最終更新: 2026-08-09 17:20 JST

## 目的

`nonworks.online` を、NON WORKSが公開するプロダクトとデザイン品質を一か所で確認できる公式の入口として育てる。

## 判断基準

- 公開中の実装・URL・説明を一致させる
- 作品ページから公式トップへ戻れる関係を保つ
- 架空作品は実在サービスと誤認されない表記を残す
- スマホ、キーボード操作、動きの軽減設定を含めて品質を確認する
- `main` は本番、機能追加は `codex/` ブランチで検証してから統合する
- 作品ごとのソースと静的出力の対応を、コミット・PR・引き継ぎ文書で追跡できる状態にする
